# olist_dashboard.csv

Table aplatie (faits + dimensions) exportée depuis DuckDB après transformation dbt, pour alimenter le tableau de bord.

- **Source** : Brazilian E-Commerce Public Dataset by Olist (Kaggle), licence CC BY-NC-SA 4.0.
- **Usage** : non commercial, projet pédagogique (Master IA 2026, Université Cadi Ayyad). Attribution à Olist.
- **Anonymisation** : données déjà anonymisées par Olist, aucune ré-identification n'est tentée.
- **Transformations** : voir `olist_dbt/` (staging, intermediate, marts). Commandes annulées et indisponibles exclues.
